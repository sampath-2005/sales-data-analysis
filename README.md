# Sales Data Analysis Project

## Objective
Analyze retail sales data to identify trends and insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Technology category has highest sales
- Phones are top-performing sub-category
- West region contributes the most revenue
- Consumer segment dominates
- Sales show monthly variation

## Project Files
- analysis.ipynb → main analysis notebook
- project.pdf → project summary

## Conclusion
This project demonstrates data cleaning, exploratory data analysis, and visualization skills using Python.
